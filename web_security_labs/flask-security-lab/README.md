# Flask Security Lab

A hands-on web security project built with Python and Flask to demonstrate common web application vulnerabilities and their secure implementations.

## Project Overview

The lab provides a practical environment for understanding how vulnerabilities work, how they can be reproduced, and how secure coding practices help prevent them.

Each module demonstrates vulnerable behavior alongside a corresponding secure implementation.

## Vulnerability Modules

| Module | Vulnerable Version | Secure Version |
|---|---|---|
| Reflected XSS | Yes | Yes |
| Stored XSS | Yes | Yes |
| DOM-based XSS | Yes | Yes |
| File Upload | Yes | Yes |
| Path Traversal | Yes | Yes |
| Command Injection | Yes | Yes |
| CSRF | Yes | Yes |
| SSRF | Yes | Yes |
| JWT  | Yes | Yes |
| SQL  | Yes | Yes |
| Race conditions | Yes | Yes |
## Technologies

- Python
- Flask
- HTML
- JavaScript
- Werkzeug
- Flask-WTF / CSRF Protection

## Learning Objectives

- Understand common web application vulnerabilities
- Compare vulnerable and secure code
- Practice identifying security weaknesses
- Understand input validation and output encoding
- Explore CSRF protection mechanisms
- Apply secure coding principles

## Demonstration Approach

Each module is designed to demonstrate:

1. The vulnerable implementation
2. How the vulnerability can be reproduced in a controlled environment
3. The security weakness behind the behavior
4. The secure implementation
5. Why the mitigation works

## Environment

- Python 3
- Flask
- Kali Linux

## Disclaimer

This project is intended strictly for educational purposes. All demonstrations should be performed locally or in authorized testing environments.
