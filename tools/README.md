# Security Tools & Technical Notes

This directory contains practical notes, command references, and small scripts related to cybersecurity tools.

## Tools & Technologies

### Network Enumeration
- **Nmap** — Network discovery and port scanning.
- **Gobuster** — Directory and DNS enumeration.
- **FFUF** — Web fuzzing and content discovery.

### Web Application Security
- **Burp Suite** — Web traffic interception and security testing.

### Network Tunneling & Pivoting
- **SSH** — Secure remote access and port forwarding.
- **Ligolo-ng** — Tunneling and network pivoting.

### Programming
- **Python** — Scripting and security automation.

## Documentation Format

Technical notes may include:

1. Tool purpose
2. Installation and configuration
3. Common commands
4. Practical examples
5. Command output analysis
6. Limitations and security considerations

## Learning Objectives

- Understand how security tools work
- Improve enumeration techniques
- Interpret technical output
- Automate repetitive tasks
- Document practical findings
